# Referee Management Application

A mobile application developed for referee scheduling, availability management, and match assignment.

## Project Overview

This project was developed to simplify referee organization processes. Referees can submit their weekly availability, while administrators can assign referees to matches based on their schedules.

## Technologies

- Flutter
- Dart
- Firebase
- Firestore

## Features

### Administrator

- Referee management
- Match management
- Referee assignment
- Schedule tracking
- Availability control

### Referee

- Weekly availability submission
- Assigned match tracking
- Schedule viewing
- Notification support

## Database

- Firebase Authentication
- Cloud Firestore

## Future Improvements

- Push notifications
- Calendar integration
- Automated referee assignment
- Match statistics dashboard
